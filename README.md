# Brand Stock Tracker — متابعة مخزون العلامات

تطبيق بسيط لمتابعة مخزون العلامات التجارية المحلية: الاستلام، المبيع، المفقود، المرتجع، والجرد.
React + TypeScript + Vite + Bootstrap 5 (RTL). البيانات تُحفظ في `localStorage` داخل المتصفح.

## التشغيل

```bash
npm install
npm run dev      # للتجربة على http://localhost:5173
npm run build    # ينتج مجلد dist يمكن رفعه على أي استضافة ثابتة
npm run preview  # لتجربة نسخة البناء
```

يتطلب Node 18 أو أحدث.

## هيكل الكود

```
src/
  types.ts            أنواع البيانات
  store.tsx           الحالة العامة + الحفظ في localStorage
  lib/logic.ts        كل المنطق (حركات المخزون، الاستيراد، الإحصاءات) بدون React
  lib/excel.ts        قراءة وتصدير ملفات Excel (مكتبة xlsx)
  components/         Modal, Toast, ProductPicker, MovementForm, MovementsTable
  pages/              Dashboard, Brands, Inventory, ImportPage, Movements,
                      StockCount, Reports, Settings
```

## كيف يعمل المخزون

| الحركة | الأثر على الكمية |
| ------ | ---------------- |
| استلام | + |
| مرتجع  | + |
| مبيع   | − |
| مفقود  | − |

- الكمية لا تتغير إلا عبر حركة مسجّلة (لا تعديل مباشر للرقم).
- لا يُسمح بحركة تجعل الرصيد سالباً.
- **الاستيراد من Excel:** معاينة أولاً، ولا يتغير شيء قبل التأكيد. تختار صراحةً بين
  «استلام مخزون جديد» (تُضاف الكميات) و«تحديث المخزون» (تصبح الكميات هي الفعلية، والفرق يُسجَّل
  استلاماً أو مفقوداً).
- **الجرد:** الفرق السالب يُسجَّل «مفقود» والموجب «استلام»، مع السبب في الملاحظات.

## ملاحظات

- البيانات محلية لكل متصفح/جهاز. استخدم «الإعدادات ← نسخة احتياطية» بشكل دوري.
- حد تنبيه النقص (افتراضي: كمية ≤ 2) يمكن تغييره من الإعدادات.
